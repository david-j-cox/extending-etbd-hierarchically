# Deprecated

This repository is retired (2026-06-02) and superseded by **`etbd-aos`**
(`github.com/david-j-cox/etbd-aos`), the canonical "Artificial Organisms Animated
by ETBD" demonstration.

Why: the "hierarchical" extension this repo's name promised was never implemented;
it remained a flat single-population ETBD proof-of-concept. `etbd-aos` provides a
tested, self-contained ETBD demonstration (verified matching on concurrent VI VI)
seeded from the more complete `ao-simulator` engine.

Not yet carried over: the **target-range reinforcement** work on the `dev` branch
(reinforce only responses whose emitted value falls within a numeric range). If
that mechanism is worth keeping, port it into `etbd-aos` as a schedule/consequence
option before this repo is forgotten.

This repo is archived (read-only) on GitHub; all branches are preserved.
